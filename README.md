## Development

This is a static HTML/CSS/JS website. To develop locally:

1. Clone the repository
2. Open `site/index.html` in a browser, or serve with any static file server
3. Edit files in `site/` — changes are immediate on refresh

## Deployment

The `site/` directory is the deployment root. Point your hosting platform (Netlify, Vercel, Cloudflare Pages, etc.) to the `site/` folder.
